# 数据源与协作补充手册

## 来源优先级

1. 政策制定或实施机关的原始页面。
2. 同级政府门户转载页面。
3. 官方开放数据平台的 API、CSV 或数据集。
4. 政务服务平台、官方发布会材料，仅用于交叉核对。
5. 媒体、电商和自媒体，只作为线索，不作为主数据。

同一政策有多级规则时，不要覆盖国家基准，而应建立：

```text
国家基准规则
   + 省级实施细则
   + 市级叠加规则
   + 区县适用条件
```

## 每个数据源必须登记

- 来源名称、行政层级、适用地区；
- 具体栏目或 API 地址；
- 采集方式：手动、低频定时、API；
- 频率：默认每周，活动期可按公告调整；
- 合规说明：公开范围、访问限制、负责人；
- 最近采集时间和下一次预计采集时间。

## 协作流程

```text
贡献者登记来源 / 上传文件 / 粘贴官方链接
        ↓
系统保存原始快照并自动抽取候选字段
        ↓
贡献者校对地区、品类、金额、有效期和证据
        ↓
提交审核
        ↓
审核员要求修改、驳回，或通过并发布
        ↓
发布记录保留来源链接、哈希、审核人和变更事件
```

## 金额口径

不要把所有金额加总。至少区分：

- 政策比例和上限；
- 固定金额或分档金额；
- 地方叠加规则；
- 官方公开的已发放总额；
- 剩余额度或活动状态。

平台首版以“政策规则”为主，不推断个人实际到手金额。

## 合规底线

- 不采集姓名、身份证、手机号、订单号等个人申领信息；
- 不绕过验证码、登录、访问控制或反爬机制；
- 低频访问，优先使用 RSS、开放 API 和官方公开栏目；
- 保留原文链接、文件哈希和抓取时间；
- 页面明确注明“非政府官方平台，最终以主管部门最新文件为准”。
