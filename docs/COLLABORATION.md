# 多人协作维护规范

## 角色

| 角色 | 权限 |
|---|---|
| 管理员 | 邀请成员、分配角色、重置密码、导入数据、审核发布 |
| 审核员 | 审核、要求修改、驳回、发布政策 |
| 贡献者 | 登记来源、采集、上传文件、提交政策草稿 |
| 只读 | 查看数据，不修改 |

## 邀请加入

1. 管理员生成邀请码并选择角色；
2. 成员打开网站注册页面；
3. 填写用户名、显示名称、密码和邀请码；
4. 注册后使用分配的角色进入平台。

首次部署时，第一个注册账号自动成为管理员。之后建议关闭自由注册，仅通过邀请加入。

## 数据维护流程

```text
贡献者登记官方来源
→ 低频采集或人工上传
→ 系统保存原文快照并抽取候选项
→ 贡献者校对地区和金额
→ 提交审核
→ 审核员修改、驳回或通过
→ 发布为正式政策
```

## 证据要求

- 只使用政府官网公开文件；
- 每条金额规则必须有原文引文；
- 保留原始链接、文件哈希和采集时间；
- 地方政策不能直接覆盖国家政策；
- 政策变更创建新版本，不要静默覆盖旧记录。

## 管理员日常操作

- 每周检查邀请码使用情况；
- 定期核查来源台账和采集失败记录；
- 审核员离职后及时停用账号；
- 为成员设置最小必要权限；
- 定期执行备份。
